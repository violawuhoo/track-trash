09危险态 · 两种变体与判定

判定规则：控件内部有墨黑图形 → 变体 B（粉底 + 墨边 + ✕）；纯文字 → 变体 A（墨底 + 橙边/投影）。
可疑背包
锈齿轮

左侧卡片里有墨黑图形，所以用粉底；右侧两个按钮只有文字，所以用墨底。两者都必须含动作词或 ✕，颜色不是唯一线索。
