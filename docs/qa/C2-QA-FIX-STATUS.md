## 4. 报告未覆盖、仍然不保证的项

原报告 §6「我无法验证的项」全部**仍然成立**，本轮未新增验证能力：

- **真机 / 浏览器端到端体验**：`apps/web` 仍无测试运行器，React 组件（图鉴面板、确认页、结局页、背包抽屉、日志面板）**从未在真实 DOM 里点过**。UI 布局、遮挡、点击热区、动画、键盘导航、`aria` 均未验证。
- **Pixi.js 渲染层**：世界层数据正确性已验，**画面本身未看过**。
- **云端真机联调**：A 项用 `app.inject()` 进程内注入，**未起真实端口**、未走真实网络、**未验 CORS / 鉴权 / 限流在真实链路上的行为**。
- **Postgres 分支**：`DATABASE_URL=postgres://` 分支**完全未测**（本地无 Postgres 实例）。
- **多端并发冲突**：「同一 device 从两台设备登录」未测；`syncFromCloud` 只在 `screen === 'start'` 时生效，**玩家在游戏中途切标签页会静默忽略云端档案** —— 这条交互后果仍未做 UI 层验证，**建议列为 v3.1 待办**。
- **性能**：10 万次随机模拟是逻辑模拟，非性能压测。真机帧率、内存、`distribute()` 在大背包下的耗时未测。
- **长周目边界**：cycle 1→2→3 已测；cycle=10+、反复开新周目 50 次等极端档案未测。
- **音频 / 触感 / 移动端适配**：纯桌面 Web 假设。
