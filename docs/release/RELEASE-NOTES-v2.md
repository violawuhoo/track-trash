# 《好垃》v2.0 首发补丁说明

> 你迫降在那颗被前人开发过的废弃星球上，已经过了一些天。
> 导航 AI 依旧只剩嘴，但星球变了——现在你真的可以在上面走了。

## 这次更新了什么

### 星球开放了：从「翻区域列表」到「用脚丈量」

- **开放世界拾取**：v1 里你点一下区域标签、等一个「搜索 +1 天」的结果列表；v2 里物品就散落在星球表面，**控制小人走近，自动拾取**。搜索按钮没有了——那玩意儿本来就不科学，捡垃圾哪有不弯腰的。
- **Pixi 世界层**：星球、地形、雾障全部换成实时渲染的纸片世界，相机跟着小人走，缩小放大多档自适应。
- **硬保底还在，而且更老实**：当前阶段缺什么标签，星球上**必定能看到**对应物品，走过去就能捡到。不是概率，是承诺——这条红线我们拿 10 万次模拟验证过。

### 内容多了 20 件破烂

- 物品 60 → **80 件**，精确配方 24 → **36 条**，意外配对照旧满地乱跳。
- 三条支线（飞船 / 茶馆 / 生日）各有备选结局文案。
- 毒舌台词覆盖：首次进区域、合错、保底生效，AI 的嘴依旧很碎，但从不攻击你。

### 新手上路前 90 秒有人带

- 引导状态机：点地面 → 走近拾取 → 第一次合成，一步步提示，**读档不重播**，捡够 4 次之后彻底闭嘴。
- 老玩家（或读档）直接跳过，不碍事。

### 云存档（增强，不是依赖）

- 换设备、清缓存不丢档，匿名设备 ID，无需账号。
- **后端只是增强**：断网、后端休眠、接口失败，全部静默降级到本地存档，照玩不误。

### 时间模型微调

- **合成 +1 天，拾取不推进时间**。逛星球不再有倒计时压迫——捡一天破烂也是正经的一天。

## 操作方式

| 平台 | 操作 |
|---|---|
| 手机 | 点地面移动；点贴纸即走近拾取；背包在 HUD 右上角 |
| 网页 | 鼠标点击移动，或 WASD / 方向键；背包抽屉内双槽合成 |

判定优先级没变：**阶段目标 > 支线 > 精确配方 > 风险物品 > 意外配对 > 兜底**，永远有产物。飞船三件套不齐也能强行起飞，一半机会——祝你好运。

## 已知问题（如实汇报）

1. **没有音效**。整个游戏目前是静音的。音效已在计划内，排后。
2. **性能实测达标，遗留一项已定位的渲染优化**。生产构建实测：Lighthouse 移动端性能分 98、4 倍 CPU 降速（模拟中端安卓）连续移动 60 秒平均 59.6fps、首屏 JS 158.6KB（gzip）。有一个已定位的小问题：每次拾取物品的瞬间可能感到一顿（背包界面重渲染所致），修复方案已定，下个冲刺排期。真机帧率尚未实测，特别老的机型请先用桌面浏览器玩。
3. **首次进入需要联网加载页面资源**；加载完成后断网可完整通关（云存档失败会自动降级，不弹错误、不挡游玩）。
4. **页面刷新后小人回到坠毁点**。坐标刻意不入存档，这是设计决定，不是丢档。

## 存档说明

- 本地存档 schema 升级为 v2；**不做旧档迁移**——由于 v1 版本从未在线上发布过，不存在需要挽救的玩家存档。如果你在本地测过 v1，进度会重开，望理解。
- 物品 ID 全部向后兼容，只增不改。
