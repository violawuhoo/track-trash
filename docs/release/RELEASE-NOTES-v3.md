# 《好垃》v3.0 补丁说明

> 你迫降在那颗被前人开发过的废弃星球上，已经过了一些天。
> 导航 AI 依旧只剩嘴，星球却变得更吵了——前任留了字，火箭在长，你的背包开始跟你计较。

## 这次更新了什么

### 星球上有了前任：八篇记录，靠合成翻出来

- 前任机修工**陈九**在这颗星球上待过。他留下 **8 篇私人记录**，散落在合成表里——每篇对应一件「载体」物品，合出来才能读。
- 读记录有门槛，但不是合成次数门槛：**天数、阶段、建设期进度**到了才翻得开。第 8 篇要等你把建设期走满。
- HUD 多了「记录」入口，已读篇数以角标形式标在按钮上。读过的记录，**再走一遍时不用重读**。

### 建设期：垃圾开始变成家

- 阶段 3 的目标链从「造三样东西」变成一条完整的建设线：**告示 → 发电机 → 时漏**，走满才算建设期完成。
- 你在星球上造的东西**真的留下了**：火箭在坠毁点一节一节长（四槽各就各位才像艘船），基地里会陆续落地 8 种景物。
- 发射窗口依旧软性地挂在**第 40 天前后**——不催你，但星星在那个位置确实亮一点。

### 第四条支线：留下来

- 「留下来」支线正式开门：**落脚、营生、熟人**三个槽位，全按具体物品判定——被这个地方承认，得有凭据。
- 结局文案备好了。你没有走，石头多了一个会回来的邻居。

### 世界线改版：万物皆原料，合成要有理由

- **每条配方都有了「为什么」**。点开合成结果，先告诉你这两件破烂凭什么能拼在一起——功能继承、材质拼接、气质共鸣，总得占一样。
- **11 个曾经的死胡同意外产物全部接入二阶配方**，星球上不再有「合出来就只能看着」的东西。
- **第五支线「混沌线」开门**：把那些莫名其妙的合成物一路合到底（轮廓 → 声音 → 答案），结局是——你终于知道自己是什么了。
- 飞船线改**四槽制**：动力 / 导航 / 外壳 / 生命维持。以前合出来不算通关的废件，现在全计入。
- HUD 常驻显示你当前的**世界线倾向**；某条线的倾向攒过线时，AI 会撩你一句——去不去随你，判定从不因此改变。

### 乐趣三件套：背包会满，合成会爆，星球会长

- **背包 10 格，满了真的满了**。新东西捡不动，得扔——扔整叠免费，不耗天数，但扔什么现在是真选择。
- **杰作时刻**：约两成合成会跳出双倍产出，合成结果里会标出来。同样的两件破烂，运气差一倍。
- **火箭与基地落地成景**（见上「建设期」）——合掉的东西不会消失，它变成了星球的一部分，且与背包解耦：部件用掉，景还在。

### 界面分区：背景、地面、产物，各归各位

- 界面重排为三层：**世界层**（背景 + 地面上散落的物品，只读不抢戏）→ **底部信息卡**（靠近弹出）→ **右侧工作台**（产物架 + 合成槽 + 背包）。
- **拾取改了**：v2 里走近就自动进包；现在走近只弹信息卡——**点「拾取」按钮，或者直接点星球上那件东西，才进包**。手不残了，选择权回来了。
- 背包里新增**产物架**：最近合成的 8 件成果横排放着，点一下看详情。你造出来的东西，值得一个不被背包按钮挡住的位置。

### 再走一遍：结局之后，星球还在

- 达成结局后可以**再走一遍**。开始前会给你一张**白纸黑字的清单**：哪些档案保留（已解锁结局、读过的记录、走过的支线、纪念品），哪些清零（背包、天数、阶段进度、建设期）。
- 图鉴面板扩到 **6 格**——五条支线加混沌线各占一格，灭不灭的都记着。
- 确认页的每个字段都从规则内核读取，**清单和实现永远一致**——我们拿守恒断言盯着：改实现不改文案会红，改文案不改实现也会红。

## 修了什么

- **结局页显示错结局**：支线完成时结局 id 没落盘，图鉴和结局页会张冠李戴。已修。
- **主菜单「重开」会清空全部档案**：包括你辛苦攒的周目记录。已修，重开现在只开新局。
- **提示条步号越界**：阶段切换瞬间提示条会闪出一个不存在的步号。已修。
- **拾取瞬间卡顿**：背包重渲染导致，已修；HUD 改细粒度订阅，捡个垃圾不再牵动整块面板。

## 操作方式

| 平台 | 操作 |
|---|---|
| 手机 | 点地面移动；**走近弹信息卡，点「拾取」或点物品才捡**；背包与记录入口在 HUD 右上角；产物架在背包抽屉顶部 |
| 网页 | 鼠标点击移动，或 WASD / 方向键；背包抽屉内双槽合成 |

判定优先级没变：**阶段目标 > 支线 > 精确配方 > 风险物品 > 意外配对 > 兜底**，永远有产物。飞船四槽不齐也能强行起飞，一半机会——祝你好运。

## 已知问题（如实汇报）

1. **没有音效**。整个游戏目前是静音的。音效已在计划内，排后。
2. **真机帧率尚未实测**。生产构建实测数据来自 v2.0 版本：Lighthouse 移动端性能分 98、4 倍 CPU 降速（模拟中端安卓）连续移动 60 秒平均 59.9fps、首屏 JS 158.7KB（gzip）。v3 内容增量后包体有所增长，帧率未复测，特别老的机型请先用桌面浏览器玩。
3. **首次进入需要联网加载页面资源**；加载完成后断网可完整通关（云存档失败会自动降级，不弹错误、不挡游玩）。
4. **页面刷新后小人回到坠毁点**。坐标刻意不入存档，这是设计决定，不是丢档。

## 存档说明

- 本地存档 schema 仍为 **v2**，**不强制迁移**：新增字段（建设期产物、日志获得记录、周目档案）在读档时自动补默认值，老档接着玩。
- 物品 ID 全部向后兼容，只增不改。
- 「再走一遍」保留什么、清零什么，**以游戏内确认页清单为准**——那份清单是从规则内核直接读的，比任何文档都可信。
