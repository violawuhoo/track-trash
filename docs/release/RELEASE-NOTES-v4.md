# 《好垃》v4.0 补丁说明

> 你迫降在那颗被前人开发过的废弃星球上，已经过了一些天。
> 但这一遍和上一遍不会一样了——远处开始出现一些解释不清的东西，而星球决定不再把每一步都提前告诉你。

## 这次更新了什么

### 每条命都不一样了：远处的迹象

星球上每周目会出现 **3 处「迹象」**。它们不在合成表里，也不归硬保底管——就是远处的一些东西。你**自己走过去，点它**，换一句台词，有时换一件材料：

| 迹象 | 窗口期 | 点它的好处 |
|---|---|---|
| 不属于任何灯的光 | 第 3–6 天 | 水晶 |
| 市场方向升起的细烟 | 第 8–12 天 | 燃料 |
| 远处靠着的假人 | 第 10–16 天 | 尴尬 |
| 石头堆里混进的新声音 | 第 12–18 天 | 石头 + 心情 |
| 天上又掉下来的小的 | 第 20–26 天 | 照片 |
| 四十天前后的流星 | 第 34–40 天 | 什么都不给——但它从来不解释为什么是四十天 |

- 抽哪 3 处、出现在哪，由**本局种子**决定：新开一局一个剧本；**再走一遍，又是另一个剧本**。
- 三处迹象的窗口期**互不重叠**，同一天不会撞见两处；位置在整个窗口期内稳定——看中了不用急，它跑不了，但只会给你一次。
- 迹象只出现在**已解锁的区域**里，走不到的地方不会有。
- **老存档不受影响**：没有种子的旧存档走原来的固定剧本，一处迹象都不会冒出来。

### 支线不再死磕第三天

- 原先奶茶店、生日这些支线要等**建设期**才有判定——材料在探索期就齐了，人却只能干等。
- 现在**探索期攒齐就能达成**。想开奶茶店，第 10 天就能开，不用再看日历。
- **飞船线是故意的例外**：四槽部件仍然只在第 3 阶段触发判定，起飞入口也仍然锁第 3 阶段。阶段 2 攒齐四件套不会直接送你回家——那条捷径堵上了，但探索期该有的自由还给你。

### 提示条学会了闭嘴

- 合成提示不再命令你「先把前面那步做完」。现在它只说：**先做前面的也行，先造它也行**——顺序是你自己的事。
- 这只是第一次减量。后面的更新里它会继续闭嘴。

### 结局之后可以反悔

- 达成结局后如果后悔了，结局页多了一个出口：**再逛逛**——回到星球上接着捡垃圾，不用重开这一局。
- 已解锁的结局、读过的记录、走过的支线都还在。反悔只是反悔，不是清零。

### 图鉴有了未知栏

- **图鉴未知栏**：还没撞见的内容不再只是不在格子里——未知栏用「?」占着，剪影像个提醒：这儿有东西，只是你还没见着。

## 对齐与修复

- **日志载体记账对齐**：万一日志载体出现在场景里（而不是合出来），捡到即算获得那段记录——两条路现在一个口径。
- 判定优先级没变：**阶段目标 > 支线 > 精确配方 > 风险物品 > 意外配对 > 兜底**，永远有产物。

## 操作方式

| 平台 | 操作 |
|---|---|
| 手机 | 点地面移动；走近弹信息卡，点「拾取」或点物品才捡；**迹象不走信息卡，点它即触发**；背包与记录入口在 HUD 右上角（撞过结局后还会多一个「结局」入口）；产物架在背包抽屉顶部 |
| 网页 | 鼠标点击移动，或 WASD / 方向键；背包抽屉内双槽合成 |

## 已知问题（如实汇报）

1. **没有音效**。整个游戏目前是静音的。音效已在计划内，排后。
2. **真机帧率尚未实测**。Lighthouse 移动端性能分 98、4 倍 CPU 降速（模拟中端安卓）连续移动 60 秒平均 59.9fps——以上为 v2.0 数据；首屏 JS 现为 183.5KB（gzip，v4.0 生产构建实测，v2.0 时为 158.7KB）。v3/v4 内容增量（含迹象世界实体）后帧率未复测，特别老的机型请先用桌面浏览器玩。
3. **首次进入需要联网加载页面资源**；加载完成后断网可完整通关（云存档失败会自动降级，不弹错误、不挡游玩）。
4. **页面刷新后小人回到坠毁点**。坐标刻意不入存档，这是设计决定，不是丢档。

## 存档说明

- 本地存档 schema 仍为 **v2**，**不强制迁移**：新增字段（本局种子、已撞见的迹象）在读档时自动补默认值，老档接着玩、走固定剧本。
- 本版**没有新增任何物品**——迹象奖励全部复用现有材料，物品 ID 依旧只增不改。
- 「再走一遍」的确认清单里多了两项：**这一局的剧本**、**这一局撞见的迹象**。保留什么、清零什么，**以游戏内确认页清单为准**——那份清单是从规则内核直接读的，比任何文档都可信。
